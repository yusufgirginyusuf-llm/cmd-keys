Cmd Keys Help

Getting started

Pick your Mac layout on Home. Every key then types what's printed on it, and the Mac shortcuts work. Cmd Keys keeps running in the notification area when you close this window; click the ⌘ icon to come back.

Typing

  • Option (⌥) + a key types the Option-layer characters, e.g. ⌥2 → ™.
  • Orange keys on the Keyboard page are accents: press one, then a letter. ⌥E then E → é.

Shortcuts

⌘C, ⌘V, ⌘Z, ⌘S… work like Ctrl. ⌘Tab switches apps, ⌘Q quits, ⌘Space opens search, ⌘⇧4 takes a screenshot. Switch any group off on the Shortcuts page.

Pausing

Press Ctrl + Option + Cmd + K to pause or resume. Add games or remote-desktop apps on the Apps page and Cmd Keys pauses itself while they're in front.

More than one keyboard

On Devices, turn on “Only remap my Mac keyboard” to leave a laptop's own keyboard the Windows way. Mark a keyboard as a Mac keyboard there if it isn't recognized.

Something's off?

  • The key left of 1 and the key left of Z swapped: turn on the swap on the Keyboard page.
  • Nothing happens in an app running as administrator: Windows doesn't let normal apps send keys there.
